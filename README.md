# ❤️ Favorite Items Toggle

An interactive **Favorite Items List** built using **HTML, CSS, and JavaScript**. Users can click the heart icon beside each item to mark it as a favorite or remove it from favorites.

## 🚀 Features

- 📋 Displays three items in an unordered list
- ❤️ Each item has a favorite heart icon
- ♡ Empty heart represents an unfavorited item
- ♥ Filled heart represents a favorited item
- 🔄 Clicking the heart toggles between empty and filled states
- 🎨 Filled hearts change color using CSS
- 🖱️ Includes a hover effect for the heart icons
- ♻️ Uses JavaScript `classList.toggle()` for switching the `filled` class

## ⚙️ How It Works

1. JavaScript selects all elements with the `.favorite-icon` class.
2. `forEach()` goes through each heart button.
3. A click event listener is added to every heart.
4. When a heart is clicked, the `filled` class is toggled.
5. If the heart becomes filled, the heart symbol changes to a filled heart.
6. Clicking it again changes it back to an empty heart.
